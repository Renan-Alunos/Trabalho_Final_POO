A Farma Aura é um sistema de farmácia online desenvolvido em Java como projeto acadêmico da disciplina de Programação Orientada a Objetos (POO).

O sistema simula a compra de medicamentos e outros produtos farmacêuticos, permitindo que clientes realizem pedidos e que o administrador gerencie o catálogo, o estoque e as vendas.

O projeto possui duas formas de interação: um menu pelo terminal e uma interface gráfica desenvolvida com Java Swing. Ambas utilizam a mesma lógica de negócio.

Funcionalidades
Visitante
- Consultar catálogo.
- Criar uma conta.
- Realizar login.
Cliente
- Realizar compras.
- Gerenciar carrinho.
- Realizar pagamentos simulados.
- Consultar histórico de compras.
Administrador
- Gerenciar estoque.
- Cadastrar produtos.
- Alterar preços.
- Consultar relatórios de vendas.
